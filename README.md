# Comet's Cocoa

Serve hot cocoa to the elves and candy pasta to the reindeer in Santa's Workshop. Get the orders out
fast and right, or the workshop falls behind on its toys! Play it at https://braickish.github.io/comets-cocoa/

Static site, no build step: `python3 -m http.server 8770` and open http://127.0.0.1:8770/. `npm test` runs the logic tests.
